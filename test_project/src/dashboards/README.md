# Operations Dashboard Starter

This folder contains SQL queries to build an AI/BI dashboard for pipeline operational tracking.

## Suggested widgets

1. KPI counters:
   - `rows_loaded`
   - `rows_quarantined`
   - `quarantine_rate_pct`
   - `avg_trip_minutes`
2. Line chart:
   - `rows_loaded` vs `rows_after_quality_filters` by `metric_date`
3. Line or bar chart:
   - `rows_quarantined` by `metric_date`
4. Line chart (optional):
   - `avg_runtime_minutes` and `est_cost_usd` from `demo_operational_metrics`

## Data source

Primary source table:
- `pipeline_observability_metrics` generated by:
  - `test_project/src/TestProject_DatalakeToGold.ipynb`

## Free account limitations

On free/trial workspaces, the following are common constraints:

1. Unity Catalog system tables may be unavailable (for example `system.billing.usage`).
2. Serverless SQL warehouse options may be limited.
3. Account-level billing datasets and advanced observability can require paid tiers or admin enablement.

If those limits apply, you can still demo end-to-end value by using:

1. Data quality and throughput metrics from `pipeline_observability_metrics`.
2. Runtime and cost placeholders in `demo_operational_metrics` populated by a scheduled SQL or notebook task.
